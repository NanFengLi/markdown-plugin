# 本地 Markdown 阅读器

一个面向 Chrome 与 Microsoft Edge 的 Manifest V3 扩展。它可以直接读取你选择的本地 Markdown 文件夹，并提供类似桌面笔记软件的目录树、大纲和阅读界面。

## 已实现功能

- 同时添加多个互不相干的本地文件夹，递归发现 `.md`、`.markdown`、`.mdown`、`.mkd` 文档
- 多目录工作区支持同名目录自动区分、单独移除、统一刷新和下次启动恢复
- 目录树与当前文档大纲一键切换
- 目录按名称、文件大小或修改时间排序，支持升序/降序
- 文件夹置顶、显示/隐藏点号开头文件
- 一次展开指定目录层级，也可逐个展开、折叠全部
- 文件搜索、当前标题滚动跟随、标题锚点跳转
- 常用 Markdown：标题、强调、删除线、链接、图片、代码块、引用、列表、任务列表、表格、front matter
- 支持 Markdown 相对链接和同一文件夹中的相对图片
- 代码块离线语法高亮，支持 JS/TS、Python、JSON、Shell、HTML、CSS、SQL、Java/C/C++/Go/Rust、YAML、Markdown，并可自动识别未标注语言
- 记住上次选择的文件夹；浏览器重启后由用户确认即可重新连接
- 拖放文件或文件夹、深色模式、响应式布局、打印样式和键盘快捷键
- 完全本地运行：不上传文档，不申请网络或全盘文件权限

## 安装（Chrome）

1. 解压发布包，保留完整的 `local-markdown-reader` 文件夹。
2. 地址栏打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的 `local-markdown-reader` 文件夹。
6. 固定工具栏上的“本地 Markdown 阅读器”，点击图标即可打开。

Windows 和 macOS 的安装步骤相同。

## 安装（Microsoft Edge）

1. 地址栏打开 `edge://extensions/`。
2. 打开左侧“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择包含 `manifest.json` 的 `local-markdown-reader` 文件夹。

Windows 和 macOS 使用同一份扩展文件。

## 使用

- 点击“选择 Markdown 文件夹”或“添加文件夹”可连续加入多个目录；每次只会授予所选目录的只读访问权限。
- 顶层目录右侧的 `×` 只会将该目录移出工作区，不会删除电脑上的任何文件。
- 左侧“目录 / 大纲”切换文件树与标题导航。
- 左侧右上角的滑杆按钮打开排序和展开层级选项。
- 文件内容在外部修改后，点击文件夹名称旁的刷新按钮重新扫描。
- 也可拖入一个 Markdown 文件或文件夹直接打开。

快捷键：

- `Ctrl/⌘ + O`：选择文件夹
- `Ctrl/⌘ + Shift + O`：打开单个文件
- `Ctrl/⌘ + F`：搜索文件
- `Ctrl/⌘ + B`：切换目录 / 大纲
- `Ctrl/⌘ + \`：收起 / 展开侧栏
- `Ctrl/⌘ + Shift + M`：从任意页面打开阅读器（可在浏览器扩展快捷键中修改）

## 隐私与权限

扩展只声明 `storage` 权限，用来保存界面偏好。文件夹访问由 Chrome/Edge 的系统选择器授权，扩展无法读取未选择的路径。所选句柄只保存在浏览器本地 IndexedDB 中，文档内容不会发送到网络。

## 开发与验证

项目不依赖 npm 第三方包：

```bash
npm test
npm run check
```

如修改 `manifest.json` 或源码，在扩展管理页点击该扩展的“重新加载”即可。

## 已知边界

- 浏览器目前没有通用的本地文件变更监听接口，因此外部修改后需要点击刷新。
- 内置 Markdown 渲染器覆盖常用语法，但不执行 Markdown 中的原始 HTML 或脚本，以避免本地文档注入扩展页面。
- Chrome/Edge 需要较新版本以使用文件系统访问 API；较旧版本会自动回退到文件输入方式，但无法在重启后恢复文件夹权限。
